# ÉTERNA STUDIO v27 — публикация приглашений одной кнопкой

## Состояние
Реализована кнопка «Опубликовать сайт» в тестовом `editor-unified-test-v27.html`. Код публикации находится в `backend/cloudflare-publisher-v27.js`, который теперь указан как точка входа в `backend/wrangler.jsonc`. Ранее работающий Workers AI импортируется и продолжает обслуживать старые запросы.

**ВАЖНО: пока в Cloudflare не установлен секрет GITHUB_PUBLISH_TOKEN, публикация не сработает.** Никогда не отправляй токен в чат, не вставляй в GitHub, HTML, JS или поле пароля редактора.

## Одноразовое подключение (владелец)
1. Открой https://github.com/settings/personal-access-tokens/new .
2. Создай fine-grained Personal Access Token: Owner — твоя учётная запись; Repository access — **Only select repositories** → `iamvaga17/eterna-wedding`.
3. В разделе Repository permissions разреши **Contents: Read and write**. Остальные разрешения оставь минимальными.
4. Выбери разумный срок действия токена. Когда срок закончится, публикация перестанет работать до его обновления.
5. Скопируй токен **только в Cloudflare**: Compute → Workers & Pages → `eterna-ai-studio` → Settings → Runtime variables and secrets → Add secret. Название **`GITHUB_PUBLISH_TOKEN`**; значение — созданный токен. Сохрани/примени.
6. Существующий секрет **`EDITOR_ACCESS_TOKEN`** не меняй.
7. Открой `https://eterna-ai-studio.vaga7486.workers.dev/publish/status` — ожидается `{"ready":true}` после публикации нового Worker и настройки секрета.
8. Открой редактор `https://iamvaga17.github.io/eterna-wedding/editor-unified-test-v27.html`, выбери ранее созданный заказ или создай новый, заполни данные и фото, перейди к шагу 4.
9. Разверни «Подключение публикации» и введи **EDITOR_ACCESS_TOKEN** (не GitHub токен). Нажми «Опубликовать сайт».
10. После успешного GitHub commit будет показана ссылка `https://iamvaga17.github.io/eterna-wedding/orders/<order-id>/`. Сайт появится после завершения GitHub Pages; проверь ссылку перед отправкой.

## Безопасность и ограничения
- Коммитит файлы только в `orders/<id>/`, на ветку `main`, в фиксированном репозитории `iamvaga17/eterna-wedding`.
- API-ключ GitHub хранится только в Cloudflare Worker Secrets.
- Публикуемые сайты публичны: фото, имена, дата и тексты доступны любому со ссылкой и в истории GitHub. Получи согласие пары.
- После публикации файлы остаются публичными в истории репозитория даже при удалении. Не выкладывай чувствительные сведения.
- Для обновления сайта того же заказа используй ту же кнопку. Все файлы нового экспорта загружаются в один GitHub commit.
- Крупный файл выше 10,5 МБ или общий пакет с очень большим числом файлов будет отклонён. При большом наборе фото лучше уменьшить их размер.
- Автоматическая публикация **не гарантирует** мгновенную готовность GitHub Pages: подтверждение коммита не равно успешной сборке сайта.
- Старый шаблон `legacy` пока не поддерживается; поддерживаются ÉTERNA 12.0 и «Срочный выпуск».
- RSVP в «Срочном выпуске» остаётся демонстрационным.
- Не проверено реальным запросом до настройки токена; тестовый код прошёл синтаксическую проверку.
