# ИИ-фотостудия v20 — подключение генератора

Файлы:
- `editor-unified-test-v20.html` — тестовый редактор с кнопкой «Сгенерировать все 3 сцены»
- `backend/image-worker-v20.mjs` — отдельный серверный обработчик Cloudflare Workers

## Что сделано
Два исходных фото — одно жениха и одно невесты — повторно передаются в каждую из трёх генераций (репортаж, архив, прогноз). Результаты сохраняются локально в браузере как ожидающие проверки. Они **не заменяют** текущие картинки до нажатия «Применить на сайт». Фото и ключи не коммитятся в GitHub.

ИИ-модели не могут гарантировать 100% идентичность лиц и тел в разных сценах. Проверяйте сходство каждой генерации и, если нужно, повторяйте её.

## Развёртывание

1. Создайте приватный Cloudflare Worker (через Dashboard). Загрузите туда содержимое `backend/image-worker-v20.mjs` как модуль Worker.
2. Добавьте Secrets (именно secrets, не общедоступные переменные):
   - `OPENAI_API_KEY` — API-ключ сервиса изображений.
   - `EDITOR_ACCESS_TOKEN` — **отдельный длинный случайный пароль** для запросов редактора (НЕ API-ключ).
   - `ALLOWED_ORIGIN` — `https://iamvaga17.github.io`.
   - Опционально `IMAGE_MODEL` — `gpt-image-2.5-flare` (используется по умолчанию).
3. В редакторе v20 выберите «Срочный выпуск», раскройте «Подключение генератора», введите HTTPS-адрес Worker и `EDITOR_ACCESS_TOKEN`. Значения не записываются в локальное хранилище.
4. Добавьте два исходных фото, подтвердите разрешение пары, нажмите «Сгенерировать все 3 сцены». Генерация использует платный API: три отдельных запроса, стоимость зависит от тарифов провайдера.
5. Проверьте все полученные фотографии и нажмите «Применить на сайт» у понравившихся вариантов.

**Без развёрнутого сервера генерация пока недоступна.** Наличие HTML и Worker в GitHub не означает, что backend развернут.

## Безопасность
- GitHub Pages — публичный статический хостинг. Никогда не вставляйте `OPENAI_API_KEY` в HTML, JS или поле пароля в редакторе.
- `EDITOR_ACCESS_TOKEN` должен быть длинным, уникальным и передаваться только по HTTPS. CORS — не замена авторизации.
- Фото отправляются только после явного подтверждения и нажатия кнопки. Получите согласие обоих людей на обработку фото.
- Данные черновиков и полученные изображения хранятся в IndexedDB/localStorage браузера: сохраняйте резервные копии; это не защищённое облачное хранилище.
- Перед коммерческим использованием добавьте лимит расходов/частоты запросов, отдельные пользовательские аккаунты и удаление персональных данных по запросу.
- В тестовой версии нет автоматического экспорта персонализированного «Срочного выпуска» в отдельный сайт.
