# ÉTERNA ATELIER — генерация 4 персонализированных сцен (v21)

## Файлы
- `editor-unified-test-v21.html` — единый редактор, тестовая версия
- `srochny-vypusk/editor-preview-v21.html` + `assets/editor-preview-bridge-v21.js` — предпросмотр персональных кадров
- `backend/image-worker-v21.mjs` — приватный серверный модуль Cloudflare Worker

## Как включить настоящий ИИ
1. В панели Cloudflare Workers & Pages создай Worker. В редактор кода Worker вставь содержимое `backend/image-worker-v21.mjs` и опубликуй. Это код **сервера**, а не файл публичной страницы GitHub Pages.
2. В Settings → Variables and Secrets добавь **секретные значения**:
   - `OPENAI_API_KEY`: ключ API OpenAI (платный API, отдельный от подписки ChatGPT).
   - `EDITOR_ACCESS_TOKEN`: длинный случайный отдельный пароль (не OpenAI API key).
   - `ALLOWED_ORIGIN`: `https://iamvaga17.github.io` (именно этот origin, без пути и финального `/`).
   - `IMAGE_MODEL` необязателен: по умолчанию `gpt-image-2.5-flare`; модель можно переключить на `gpt-image-2.5-sunburst` для более точного редактирования. Проверяй наличие модели в своём API-проекте.
3. Открой `https://iamvaga17.github.io/eterna-wedding/editor-unified-test-v21.html`. Выбери «Срочный выпуск», раскрой «Подключение генератора» и введи **URL опубликованного Worker** и `EDITOR_ACCESS_TOKEN` (не API-ключ). Эти два значения не сохраняются редактором.
4. Добавь исходные фотографии жениха и невесты, получи согласие каждого на их обработку сторонним ИИ, включи флажок согласия, нажми «Сгенерировать все 4 сцены».
5. На каждый кадр отправляются **оба исходных фото**: (1) пресс-конференция; (2) расследование свадебного торта; (3) архив знакомства; (4) свадебный прогноз. Ожидаемые фото сначала сохраняются как черновики. Проверь сходство и нажми «Применить на сайт» или «Отклонить».
6. Если видишь «Backend has not been configured» — в Worker не созданы секреты; «Unauthorized» — неверен `EDITOR_ACCESS_TOKEN`; «Origin not allowed» — проверь `ALLOWED_ORIGIN`; «Image service returned HTTP ...» — проверь оплату API, права на модель, лимиты и серверные логи.

**Не вставляй ключ OpenAI в поле пароля, HTML или JavaScript сайта.**

## Ограничения и безопасность
- Пока Worker **не развернут и не подключён**, кнопка не выполняет реальную генерацию. GitHub Pages сама по себе не запускает серверный код.
- Четыре последовательных запроса к API являются платными, сходство пары нельзя гарантировать на 100%.
- Перед регулярным коммерческим использованием необходимо включить лимиты и оповещения о расходах, антиабуз/ограничение числа запросов, управление доступом, политику хранения и удаления фотографий. Один общий пароль недостаточен для многопользовательского сервиса.
- Фото хранятся локально в браузере пользователя (IndexedDB), могут быть потеряны при очистке Safari. В коммерческом варианте добавь резервные копии и отдельную публикацию заказа.
- Изображения не публикуются в сайте автоматически: после генерации требуется ручное одобрение. Экспорт готового «Срочного выпуска» в отдельный опубликованный клиентский сайт ещё не реализован.
- Для генерации одного и того же узнаваемого персонажа используются одни и те же исходные фотографии. Результат всё равно нужно проверять. В будущем можно добавить «паспорт персонажей» из нескольких референсов каждого.
