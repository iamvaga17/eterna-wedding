# ÉTERNA 12.0

- Демо открывается по пути `/eterna-12/` на том же хосте, что и каталог. Это самостоятельная страница без iframe.
- В `editor.html` доступны версия 12.0 и прежний шаблон редактора. Версия в списке определяет шаблон ZIP-экспорта. Заказы и загруженные фото сохраняются в браузере.
- Для отдельного заказа настройте анкету в конструкторе, скопируйте JSON в настройки RSVP редактора и нажмите «Применить анкету». ZIP версии 12.0 содержит страницу, конфигурацию, стили, скрипты и локальные фотографии. Введённые внешние ссылки на фотографии остаются ссылками.
- Подтверждение в RSVP проверяет заполнение. Серверный сбор ответов отсутствует.
- Демо использует синтетические иллюстрации. Данные пары и программа берутся из `wedding-config.js`.
- При правке CSS или JS в `assets/` обновите имя файла хешем его содержимого и ссылку в `index.html`. Для общих скриптов обновите параметр `rev`. Предыдущие опубликованные заказы получают копию ресурсов при экспорте.
