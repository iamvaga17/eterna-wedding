# Сбор ответов в Google Sheets

Один заказ — отдельная закрытая Google-таблица и отдельное веб-приложение Apps Script. Гостям доступна отправка через URL веб-приложения. Таблица остаётся доступна только организаторам, которым вы дали права в Google Sheets.

1. Создайте Google-таблицу. В меню **Расширения → Apps Script** вставьте содержимое [Code.gs](Code.gs).
2. В настройках проекта Apps Script добавьте свойство скрипта `SPREADSHEET_ID`. Его значение — часть адреса таблицы между `/d/` и `/edit`.
3. Выберите **Развернуть → Новое развертывание → Веб-приложение**. Укажите выполнение от имени владельца и доступ «Все» (включая посетителей без Google-аккаунта). Выдайте приложению доступ к таблице при запросе Google.
4. Скопируйте адрес приложения с окончанием `/exec`. В редакторе заказа в настройках RSVP вставьте его в поле **Адрес сбора ответов (HTTPS)**, примените анкету и экспортируйте заказ.
5. После публикации заказа отправьте тестовый ответ с вымышленным именем в приватной вкладке. Вкладка «Ответы RSVP» появится после первой успешной записи. Приглашение должно показать подтверждение только после сохранения.

Адрес отправки виден в коде приглашения. Он принимает ответы без входа в Google и не выдаёт содержимое таблицы. Ссылка на таблицу и её идентификатор хранятся отдельно от HTML приглашения. Предпросмотр в редакторе и приглашение без настроенного HTTPS-адреса работают в демо-режиме.

Другой сервер также может принимать POST с телом JSON и заголовком `Content-Type: text/plain;charset=UTF-8`. После гарантированной записи он возвращает `{"ok":true,"id":"<ID запроса>"}`. Повтор запроса с тем же ID следует подтверждать без повторной записи. Для другого домена ответ должен быть доступен через CORS.
